**一粒小米，承载了一个国家的名字——社稷**

---

在中国人的谷物谱系中，稷（_Setaria italica_）是最具政治与文化象征意义的存在。它的野生祖本是随处可见的狗尾草，却在一万年间被驯化为"五谷之长"，被《说文解字》奉为"五谷之长"，被周人始祖"弃"以官名"后稷"代代相传，最终与"社"合为"社稷"——国家的代称。世界上很少有哪个国家，将自己的名字建立在一粒谷物之上，中国是其中之一。这是一段关于一粒小米如何承载一个文明的故事。

---

## 一、稷就是粟，粟就是小米

### 名称溯源

稷（_Setaria italica_），又称粟、谷子、小米，是中国人最熟悉的古老谷物。它有几个名字，对应不同的语境：

| 名称 | 语境               | 含义               |
| ---- | ------------------ | ------------------ |
| 稷   | 礼制、祭祀、典籍   | 五谷之长，国家象征 |
| 粟   | 古代农书、行政文书 | 日常粮食作物       |
| 谷子 | 北方民间俗称       | 未脱壳的粟         |
| 小米 | 现代、脱壳后       | 日常食用形态       |

《说文解字》："稷，齌也。**五谷之长**。"《风俗通义》："稷，五谷之长。五谷众多，不可徧祭，故立稷而祭之。"[4]

### 狗尾草的驯化

稷的野生祖本是随处可见的**狗尾草**（_Setaria viridis_），二者亲缘关系极近，杂交容易成功 [10]。这意味着稷的驯化门槛相对较低——古人可以在较短时间内，通过连续选择将狗尾草驯化为栽培粟。

狗尾草至今仍是中国农田中最常见的杂草之一。每当夏秋之际，路边、田埂、荒地，到处可见它毛茸茸的穗子。这株卑微的野草，孕育了华夏文明最核心的粮食作物——这个反差，本身就是农业起源最动人的故事之一。

### 驯化的关键性状

与黍类似，稷驯化的关键也是"不落粒"性状的固定。但稷还有一个独特优势——**分蘖少、穗大、籽粒多**。一株野生狗尾草的穗可能只有几十粒种子，而一株栽培粟的穗可以有数千粒种子，单穗生产力提高了几十倍。

此外，稷的生育期短（约 90–120 天），耐旱耐瘠，适应性极强。这些特性使它成为黄河流域最理想的旱地作物——在年降水量仅 400–600 毫米的黄土高原，稷是少数能稳定高产的谷物。

## 二、稷的万年驯化史

### 最早的利用证据

稷的驯化史可追溯至旧石器时代晚期。山西下川遗址（距今约 24,000–16,000 年）出土的石磨盘，被认为是最早的粟作文化先声 [10]。这些石磨盘上残留的淀粉粒显示，旧石器时代晚期的采集者已经在加工狗尾草类的种子作为食物。

北京东胡林遗址（距今约 11,000–9,500 年）的石磨盘和石磨棒上发现了粟的淀粉粒，是迄今最早有直接测年的粟利用证据 [2]。

### 关键遗址谱系

| 遗址   | 地点       | 年代（距今）      | 关键发现               |
| ------ | ---------- | ----------------- | ---------------------- |
| 下川   | 山西沁水   | ~24,000–16,000 年 | 石磨盘，粟作先声       |
| 南庄头 | 河北徐水   | ~11,500–11,000 年 | 淀粉粒，黍+粟共存      |
| 东胡林 | 北京门头沟 | ~11,000–9,500 年  | 最早直接测年的粟证据   |
| 磁山   | 河北武安   | ~10,300–8,700 年  | 早期以黍为主，后期粟增 |
| 兴隆沟 | 内蒙古赤峰 | ~7,670–7,610 年   | 1,500+ 粒炭化粟和黍    |
| 裴李岗 | 河南新郑   | ~8,000–7,000 年   | 粟作农业成熟           |
| 半坡   | 陕西西安   | ~6,800–5,600 年   | 粟为主，窖穴储粮       |

### 磁山遗址：十万斤储粮的震撼

河北武安磁山遗址（距今约 8,000 年）是粟作农业最早的规模化证据。考古学家发掘灰坑 468 个，其中 **88 个窖穴底部有粮食堆积**，堆积厚度 0.3–2 米，专家估计储粮总量达 **10 万斤以上（约 50,000 公斤）**[11]。

值得注意的是，磁山遗址早期地层（10,300–8,700 BP）以黍为主，晚期地层（约 8,700 BP 之后）粟的比例显著上升 [1]。这一变化反映了**粟逐步取代黍**的过程——因为粟产量更高、适应性更强，最终成为黄河流域的主体作物。

### 兴隆沟：世界最早的精确测年小米

内蒙古赤峰兴隆沟遗址通过浮选法获得 1,500 余粒炭化粟和黍籽粒，其中粟的年代距今约 7,650 年，是目前世界上**经过精确测年的最早的小米实物遗存**之一 [12]。

2012 年，联合国粮农组织将敖汉旗列为"**全球重要农业文化遗产**"旱作农业系统保护地。这片土地上的农民，至今仍保留着古老的粟黍品种和传统耕作方式，成为活的农业文化遗产。

## 三、稷为何是"五谷之长"

### 始终位列首席

在中国传统"五谷"中，稷始终位列**首席**。无论五谷采用哪种说法，稷始终居首 [13]：

| 五谷版本     | 五谷内容                       | 稷的位置            |
| ------------ | ------------------------------ | ------------------- |
| 《周礼》版本 | 黍、稷、稻、粱、麦、菽、麻、苽 | 第 2 位（仅次于黍） |
| 《孟子》版本 | 稻、黍、稷、麦、菽             | 第 3 位             |
| 《楚辞》版本 | 稷、黍、稻、麦、麻             | **第 1 位**         |
| 郑玄注版本   | 麻、黍、稷、麦、菽             | 第 3 位             |
| 民间通行版本 | 稻、黍、稷、麦、菽             | 第 3 位             |

虽然排序因版本而异，但**所有典籍都将稷列为"五谷之长"**，这是基于其国家地位而非产量排序。

### "禾"字：粟的象形

"禾"字的象形直接来源于粟的植株形态——一竖一横象征茎秆与叶片，顶端一撇勾勒出下垂的穗头 [13]。可见粟在中华先民心中是最基础、最本源的谷物。

由"禾"衍生出大量汉字：

| 汉字 | 含义         | 引申义     |
| ---- | ------------ | ---------- |
| 稼   | 播种         | 劳动       |
| 穑   | 收获         | 劳动       |
| 种   | 播种         | 起源、品类 |
| 秋   | 收获季节     | 时光       |
| 秦   | 秦地产禾之地 | ——         |
| 秀   | 禾乃（结实） | 优秀       |
| 秩   | 禾的次序     | 秩序、官秩 |
| 程   | 衡量禾的数量 | 法度、程序 |

> 在汉字中，"禾"字旁的字数量超过 200 个，涵盖了农业、秩序、官制、品德等核心概念。这说明粟作文化不仅是经济基础，更是中华文明的**底层认知框架**。

### "后稷"：周人始祖的官名

《尚书·舜典》："汝后稷，播时百谷。"周人始祖"弃"被任命为**后稷**（农官之长），正因稷为百谷之长。

周人将始祖"弃"的传说记载在《诗经·大雅·生民》中：

> 厥初生民，时维姜嫄。生民如何？克禋克祀，以弗无子。履帝武敏歆，攸介攸止。载震载夙，载生载育，时维后稷。

弃被舜帝任命为后稷，封于邰（今陕西武功），主管农业。**周人之所以能最终取代商朝，其农业传统是根本优势**——周人以农立国，稷是他们的守护神，也是他们的政治合法性来源。

## 四、社稷：一个国家的名字

### "社"与"稷"的合称

"社稷"是"社"与"稷"的合称——**社**为土地神，**稷**为五谷神。古代中国是农业社会，土地与粮食是国家的根本，"社稷"由此成为**国家的代称**。

帝王自称"江山社稷"，北京中山公园内的明清社稷坛，坛面铺五色土（青、红、白、黑、黄），象征天下疆土 [14]。

### 社稷祭祀：国家最高典礼

《诗经·载芟》序："春籍田而祈社稷也"（春祈）；《诗经·良耜》序："秋报社稷也"（秋报）。一年两度的社稷祭祀，是古代中国最重要的国家典礼。

| 祭祀   | 时间     | 内容                     | 意义         |
| ------ | -------- | ------------------------ | ------------ |
| 春祈   | 春分前后 | 祈求土地神、谷神保佑丰收 | 国家级祭祀   |
| 秋报   | 秋分前后 | 感谢神灵赐予丰收         | 国家级祭祀   |
| 藉田礼 | 春初     | 皇帝亲自下田耕作         | 示范天下重农 |
| 蜡祭   | 腊月     | 祭百神以报岁功           | 农业年终总结 |

### 社稷坛的形制

北京社稷坛（今中山公园内）始建于明永乐十八年（1420 年），是明清两代皇帝祭祀社稷的场所。坛为三层方形石台，上层铺五色土：

| 颜色 | 方位 | 代表区域     |
| ---- | ---- | ------------ |
| 青   | 东   | 东海         |
| 红   | 南   | 南方         |
| 白   | 西   | 西方         |
| 黑   | 北   | 北方         |
| 黄   | 中   | 中原（中央） |

> 世界上很少有哪个国家，将自己的名字建立在一粒谷物之上。中国是其中之一。"社稷"二字，凝结了中华文明对土地与粮食最深的敬畏。

## 五、粟在古代文明中的角色

### 夏商周：国力的物质基础

夏、商、周三代，粟居五谷之首，是**国家粮食供应的基石**和**祭祀礼仪的核心**。

**夏代**：二里头遗址（夏代晚期都城）出土大量粟的炭化籽粒，粟是夏人的主食。

**商代**：甲骨文中"粟"字虽不如"黍"频繁，但卜辞中"求年""受年"的对象主要是粟。商代贵族以粟酿酒、做饭，平民以粟为主食。

**周代**：周人以农立国，粟的地位进一步提升。《诗经》中"黍稷"并称，但"稷"（粟）始终是"五谷之长"，地位高于黍。

### 秦国靠粟统一六国

秦国靠关中粟作农业积累国力，最终统一六国。商鞅变法核心政策之一是"**奖励耕战**"——种粟多者免徭役，作战勇者授爵位。关中平原沃野千里，渭水灌溉便利，成为秦国的"粟仓"。

战国时期，粟的产量是衡量国力的核心指标。《孙子兵法》载："食敌一钟，当吾二十钟。"——能夺取敌人的粟等于保存自己的国力。长平之战中，秦军能持续三年围攻赵军，靠的就是关中粟的稳定供应。

### 汉代：粟作帝国的巅峰

汉代是中国粟作农业的巅峰时期。汉初《氾胜之书》专设"粟"篇，详细记载粟的栽培技术。汉武帝时期，推行"代田法"（轮作休耕），粟的亩产显著提高。

> 汉代粟的亩产约 100–150 公斤，是中国古代农业的高水平。直到宋代水稻推广后，单产才被超越。

汉代的财政体系以粟为本位：

- **田赋**：按土地征收粟
- **口赋**：人头税，可用粟折算
- **漕运**：将关东粟运至长安，供养京师
- **和籴**：官府以帛收购民间粟，充实边储

**粟就是汉代的"硬通货"**，是国家财政和军备的物质基础。

## 六、粟的农学传统：从《齐民要术》到《天工开物》

### 《齐民要术》：粟的百科全书

北魏贾思勰著《齐民要术》（约公元 533–544 年）对粟的记载最为详尽，记载了 **86 种粟的品种**，系统总结了粟的栽培技术 [15]。

核心原则是"**谷田必须岁易**"（粟田必须每年轮作）。这一原则比欧洲农业认识到轮作的重要性早了约 1,000 年。

《齐民要术》还记载了粟的品种分类：

| 类别   | 特性           | 用途         |
| ------ | -------------- | ------------ |
| 早熟种 | 生育期短，避旱 | 山地、干旱区 |
| 晚熟种 | 产量高         | 平原、水浇地 |
| 黏粟   | 含支链淀粉高   | 酿酒、做糕   |
| 不黏粟 | 含直链淀粉高   | 日常做饭     |
| 朱谷   | 籽粒红色       | 优质品种     |
| 张公斑 | 籽粒有斑纹     | 抗虫         |

### 《天工开物》：明代农学总结

《天工开物》（明代，1637 年）明确记载 [16]：

> "凡黍与稷同类，粱与粟同类。黍有粘有不粘，粘者为酒，稷有粳无粘。"

这一记载精确区分了黍（糯性）与稷（粳性）的差异，是中国古代农学对这两种作物的最终定型认知。

### 农谚中的粟

民间农谚是粟作传统的活化石：

- "谷雨前后，种瓜点豆"——谷雨节气与粟播种相关
- "头伏萝卜二伏菜，三伏种荞麦"——伏天与作物安排
- "秋分早，霜降迟，白露种麦正当时"——秋季播种时机
- "有钱难买五月旱，六月连阴吃饱饭"——粟生长的气候偏好

> 这些农谚是数千年的经验积累，至今仍在华北农村口口相传。

## 七、粟的三次衰落与重新崛起

### 第一次衰落：隋唐小麦扩张

**第一次（隋唐）：** 小麦种植面积扩大，唐德宗建中元年（780 年）推行**两税法**，将小麦列入法定征税对象，种麦可直接抵税，极大刺激了小麦种植。

两税法之前，唐代田赋只征粟（"租粟调帛"）。两税法后，"夏税"征麦，"秋税"征粟，小麦正式成为国家财政的法定作物。**这一政策转变，使小麦在北方逐步取代粟**，粟的种植面积开始下降。

### 第二次衰落：明清美洲作物传入

**第二次（明清）：** 玉米和甘薯等美洲高产作物传入，单产优势明显，粟退居山区和贫瘠地带。

玉米亩产可达 300–400 公斤，是粟的 2–3 倍。甘薯亩产可达 1,000–2,000 公斤，更是粟的 10 倍以上。在人口压力下，高产作物必然被优先选择，粟从平原主粮退居为山区杂粮。

### 第三次衰落：改革开放后的现代化

**第三次（改革开放后）：** 水利灌溉改善、化肥投入激增，小麦矮化育种和玉米杂交育种取得突破。粟的种植面积从新中国初期的 1.5 亿亩缩减至如今的约 1,500 万亩——**缩减了 90%**。

### 但粟并未退出历史舞台

2024 年全国谷子总产量约 **320 万吨**，全产业链产值达 **659.2 亿元** [13]。**"张杂谷"系列**在全国 16 省累计推广面积 4,000 万亩，增产粮食 40 多亿斤，节水 80 亿立方米 [17]。

### 现代小米品牌

| 品牌       | 产地       | 特色               |
| ---------- | ---------- | ------------------ |
| 沁州黄     | 山西沁县   | 历史上贡米         |
| 汾州香     | 山西汾阳   | 现代培育优质品种   |
| 米脂小米   | 陕西米脂   | "米脂婆姨"得名于此 |
| 赤峰小米   | 内蒙古赤峰 | 全球农业遗产地     |
| 朝阳小米   | 辽宁朝阳   | 国家地理标志       |
| 沁州黄小米 | 山西沁县   | 历史贡米           |

小米的饮食形态日益多元化：从小米粥、小米饭，到小米锅巴、小米糕点、小米面条、小米饮料。

## 八、粟与现代科技：张杂谷的奇迹

### "张杂谷"：中国农业的骄傲

"张杂谷"是由河北省张家口市农业科学院**赵治海**研究员团队培育的系列谷子杂交品种。这是继杂交水稻之后，中国在粮食作物育种领域的又一重大突破。

#### 关键数据

- **推广面积**：全国 16 省累计推广 4,000 万亩 [17]
- **增产粮食**：40 多亿斤
- **节水**：80 亿立方米（相当于 5 个密云水库）
- **亩产提升**：从 100–150 公斤跃升至 300–500 公斤

#### 为什么是奇迹

谷子（粟）长期以来被认为是"低产作物"，难以杂交。赵治海团队历经 30 余年攻关，攻克了谷子杂交育种的难题：

1. **发现谷子光温敏雄性不育系**
2. **建立两系法杂交谷子育种体系**
3. **培育出多个"张杂谷"品种**

#### 节水意义重大

粟本就是节水作物，张杂谷进一步提升了水分利用效率。在华北地下水超采严重、生态危机加剧的背景下，张杂谷的推广具有重要战略意义：

- 用水量仅为玉米的 1/3
- 在干旱、半干旱地区表现优异
- 适合华北平原"压采地下水"政策下的结构调整

> 张杂谷的推广，不仅是农业技术问题，更是国家粮食安全与水资源安全战略的重要组成部分。

## 九、粟的文化印记

### 粟与汉字

粟（禾）在汉字中留下了深刻的印记。除了前述"禾"字旁的 200 余字外，还有大量与粟相关的概念：

- **"精"**：从米从青，本义为纯净的米
- **"粗"**：从米从且，本义为粗糙的米
- **"粹"**：从米从卒，本义为纯净无杂的米
- **"粝"**：粗米
- **"粮"**：简化字，繁体"糧"，从米从量

> 汉字中关于米的字，构成了中国人对"品质"的认知框架。"精细""粗劣""纯粹""粗糙"——这些日常用词，都源自古人对粟米品质的辨别。

### 粟与成语

- **沧海一粟**：苏轼《前赤壁赋》"寄蜉蝣于天地，渺沧海之一粟"——以一粒粟比喻微小
- **不食周粟**：伯夷叔齐隐居首阳山，不食周粟而死——以粟代指政治立场
- **粟红贯朽**：钱粮堆积——以粟代指国家富足
- **寸丝半粟**：极言微少

### 粟与节日

- **腊八粥**：传统腊八粥必含小米
- **重阳糕**：以米粉制作
- **小米粥**：北方产妇"坐月子"必食，被认为滋补

### 粟与诗词

> 稻云不雨不多黄，荞麦空花早见霜。  
> 已分忍饥度残岁，更堪岁里闰添长。  
> ——杨万里《悯农》

> 春种一粒粟，秋收万颗子。  
> 四海无闲田，农夫犹饿死。  
> ——李绅《悯农》

李绅这首诗，是中国人最熟悉的咏农诗。"春种一粒粟"中的"粟"，既是具体的作物，也是"一粒种子"的象征。一粒粟，承载了中国农民最深的辛劳与希望。

## 结语：一粒小米里的中国

从下川遗址两万年前的石磨盘，到磁山遗址十万斤的储粮窖穴；从甲骨文里反复占卜的"受年"，到《诗经》中"黍稷彧彧"的田野；从周人始祖"后稷"的封号，到"社稷"二字所承载的国家——稷，这粒小小的谷物，承载了中华文明最深沉的底色。

它曾是商周的国之根本，是秦汉的硬通货，是唐宋的诗意，是明清的乡愁。它见证了华夏文明从狩猎采集走向农业定居的全过程，承载了国家信仰的重量，留下了"禾"字旁的整个汉字体系。

今天，当我们在早餐桌上端起一碗小米粥，品尝的不仅是食物的温暖，更是华夏文明最古老、最本真的味道——那两万年前，先民与一株狗尾草相遇时的智慧与坚韧。

> 一粒小米，一个中国。它没有消失，它就在每一碗温热的小米粥里，在每一个"社稷"二字的出现之处，静静诉说着这个文明最深的根。
